# 🚀 Tecboard - Landing Page

Esta é uma landing page responsiva desenvolvida para a **Tecboard**, uma solução focada em monitoramento e alertas inteligentes. O projeto foi criado como parte do aprendizado prático no curso **HTML e CSS: ambiente, estrutura e estilo** da Alura.

## 📋 Sobre o Projeto

O objetivo do site é apresentar o serviço de monitoramento em tempo real da Tecboard, destacando a importância de manter aplicações sempre ativas com alertas inteligentes. 

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Para a estruturação semântica do conteúdo.
* **CSS3**: Para a estilização, utilizando conceitos de Flexbox e Media Queries para responsividade.
* **Google Fonts**: Integração das fontes *Poppins* e *Unbounded* para uma identidade visual moderna.

## 🎨 Identidade Visual

A página segue uma estética "Dark Mode" com alto contraste:
* **Fundo**: `#0e1014` (Preto profundo).
* **Destaques**: `#9747ff` (Roxo vibrante), aplicado em botões e chamadas de texto.
* **Texto**: Branco puro para garantir legibilidade máxima sobre o fundo escuro.

## 📱 Responsividade

O layout foi planejado para se adaptar a diferentes tamanhos de tela através de pontos de interrupção (breakpoints):

* **Desktop**: Largura total de 1200px para o cabeçalho e 792px para a seção principal.
* **Tablet (768px)**: Ajuste de margens e largura para 648px.
* **Mobile (400px)**: Redução do tamanho da fonte para 20px no corpo e 40px no título, além de carregamento de imagem otimizada para telas menores.

## 📂 Organização de Arquivos

* `index.html`: Estrutura principal da página.
* `style.css`: Folha de estilo contendo resets e design responsivo.
* `/img`: Pasta contendo o logotipo e os mockups dos aparelhos celulares.
